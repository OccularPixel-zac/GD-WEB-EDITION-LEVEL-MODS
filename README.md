# GD-WEB-EDITION-LEVEL-MODS
A repository of a version of the official gd web browser trial, being able to locally run on your computer and have custom levels

# INSTRUCTIONS
1 - Make sure to download the latest release from the releases page.

2 - Extract the file and go into the folder created.

3 - **IMPORTANT, DO EVERY LAUNCH**: Type *python -m http.server 8000* inside the directory bar whilst inside of the GD WEB Folder, this will launch the game and it should go through the loading screen with all textures loaded if it sucseeded. if not, manually install all of the textures from the official version of the web trial.

# LOADING LEVELS

The levels found inside the videos i have made should be in the levels folder, just select them, move them into the assets folder, move the other level file back into the folder and rename the file to 1.txt. However, if you want to load your own levels, read the instructions down below.

**PLEASE NOTE:** The edition of the game can only run basic 1.0 objects, not even pads or orbs. I might try to edit the game files to add the portals, but the game is very obfuscated.

1 - Download your level as a .gmd file using gdshare.

2 - Open the .gmd file in any Text editing software and copy the encoded text from k4</k><s> To </s>.

3 - Paste the encoded string into a text file and set its name to 1.txt

4 - Download the mp3 of the song that you are using and rename it to StereoMadness.mp3

5 - Move the already existing 1.txt/StereoMadness.mp3 into the Levels Folder and paste the new ones inside the assets folder

6 - Relaunch the game, Make sure you also indicated what level the initial level that you replaced was and rename it accordingly to not lose track of which level is which.
